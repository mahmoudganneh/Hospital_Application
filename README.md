# نظام إدارة المستشفيات — واجهة أمامية تجريبية

واجهة React + Vite + Tailwind CSS باللغة العربية واتجاه RTL. لا يحتاج المشروع إلى Backend في هذه المرحلة؛ البيانات التجريبية محفوظة في LocalStorage بالمتصفح.

## التشغيل

يتطلب Node.js إصداراً حديثاً.

```bash
npm install
npm run dev
```

لإنشاء نسخة إنتاجية:

```bash
npm run build
npm run preview
```

## المزايا

- لوحة تحكم بمؤشرات الأداء وحركة المرضى وإشغال الأسرّة.
- إدارة المرضى مع البحث والتصفية وإضافة ملف جديد.
- تأكيد المواعيد وإلغاؤها.
- متابعة مخزون الصيدلية، وتواريخ الصلاحية، وتوريد كميات تجريبية.
- مركز تنبيهات متجاوب مع تمرير داخلي وإغلاق واضح.
- إعدادات اسم المستشفى وبيانات الحساب والسعة السريرية.
- حفظ التغييرات في LocalStorage.

## ملاحظات مهمة

هذه واجهة تجريبية وليست نظاماً طبياً معتمداً. لا تُدخل بيانات مرضى حقيقية أو معلومات صحية حساسة. قبل الاستخدام الفعلي، يلزم Backend آمن مع المصادقة وتحديد الصلاحيات والتدقيق والنسخ الاحتياطي والامتثال لمتطلبات حماية البيانات.
